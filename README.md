# Login (.NET 8, Razor)

## Introducción

API RESTful desarrollada en .NET 8 para la accion de login con usuario y contraseña. 
El diseño de la vista está elaborada en Razor Pages y consume la API.

## 📦 Tecnologías utilizadas

- ASP.NET Core 8
- Entity Framework Core 8
- SQL Server
- Razor Pages
