# 🚀 AutosEJ API (.NET 8)

## Introducción

API RESTful desarrollada en .NET 8 para la gestión de vehiculos de una agencia de autos. 
Diseñada con principios de Clean Code y los principios SOLID para facilitar el mantenimiento, escalabilidad y pruebas.

## 📦 Tecnologías utilizadas

- ASP.NET Core 8
- Entity Framework Core 8
- SQL Server


## 📁 Estructura del proyecto
	AutosEj/       

	# Configuracion a la base de datos (SQL Server)
		Config/          
	# Entidades, interfaces, clases abstractas, DTOs
		Models/              
	# Controladores
		Controllers/
	# Filtrado de datos, lógica de negocio
		Services/ 
	# Encriptacion, generador de token
		Utils/
